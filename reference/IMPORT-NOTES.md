# LomusTrack repository import

Source: https://github.com/yuldchissico-alt/jkddj (main, snapshot 48d1ab3).

The React interface, original sample data, assets, and source styles were imported. Navigation uses the existing TanStack Start framework. Choose “Explorar demonstração” on the login screen to browse sample data. Demo changes are blocked instead of falsely reporting saved or published records.

The original Python FastAPI service is preserved under original-backend for reference only. It is not deployed or executed by this project. Real authentication, persistent records, AI, webhooks, notifications, payment and ad integrations require a separate service migration and credentials. No credentials or database contents were imported.

The website-importer URL capture workflow was not used because the supplied URL is a source repository, not a running application. There is no confirmed hosted source app for paired visual/interaction comparison. Source behavior was inspected from code; preview checks do not establish original-host equivalence.
